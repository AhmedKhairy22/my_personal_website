I will talk about why Linux could be your best choice as an OS from my POV. First of all, I used to be a Windows user for all of my life, and in fact, I still use it. So I was pretty comfortable using Windows, and I heard the word "Linux" from time to time in open-source contexts as an operating system. But I did not give a shit,  and I did not really care, as I did not see Windows as anything but good. 

My real first interaction with Linux started 2 years ago, when I was at university and started learning programming. The story began when I tried to do programming using C. So I started to search for how I really could program in C using Windows without complications. I found out the process is a bit hectic, and I have to download Visual Studio Code and do some config and so on. So, using an entire IDE for a relatively simple C development setup feels like overkill. And as a minimal person, I started to look for the most direct and minimal way to do so. And, as you could guess, I found that using Linux was such a straightforward process. It is just one command, and you compile your code. So I started to find out how to install Linux. And I found that there is a way of making linux working alongside of my Windows machine; it is called [WSL](https://learn.microsoft.com/en-us/windows/wsl/install), or Windows Subsystem for Linux. Frankly, it was just a terminal, but I had the Linux behavior, environment, and functionality that I wanted. So I started to mess around and discover it more and more, and of course do my C programming stuff.

After a while, I started to use Linux inside a virtual machine to make my experience a bit real, so I could decide if it is really worth it to make it my main OS. So I installed Arch (BTW) inside a virtual machine using VirtualBox on Windows. So it has been like 2 years now since my first exposure to Linux and using it. And I admit, it is not that long a time to build a whole judgment, but during that time I was testing and trying things and figuring out things and stuff, and I have built a bit of a real, opinionated point of view of what is good about Linux and why, for me, it is considered a very good option.

First, Linux is open-source software. which is mean that its code is available to any one to see and edit on it and contrubite to it. But what is good about software being open source? First, it is very hard to put malicious or harmful code into the source code because it is seen by everyone. Also, bugs could be tracked and reported very easily and fast. Second, the features are most probably community-driven. Third, you will have a lot of tutorials, docs, and books explaining a lot of things that you might face, so it is so easy to find a solution for your issues.

It is not just about being open source. Because comparing Linux to Windows. Windows comes with a lot of features and programs and, most annoyingly, their Copilot. And for the normal users, that is not a big deal. But for a bit experienced user, you should ask yourself why the hell I should have on my machines programs that I don't know or want, especially if those are taking resources from your computer. So in Linux, you really decide what programs you want to use and customize your environment as you want. And you will find that anything you want to do has a terminal-based option if you do not use the GUI. The whole point is that you should have the freedom to make full use of the hardware and resources you own, however you see fit, including installing and running whatever software you want.

Finally, you might be a normal user; all that matters is that the piece of software you use is just working on your machine. But you have to learn how to use your software, not the software using you. And if you think that is going to be very hard, Linux has some ways to look very similar to the Windows environment, with all of these great features and a GUI. And even though I still use Windows as my main os, I know that very soon I will switch completely to Linux.
