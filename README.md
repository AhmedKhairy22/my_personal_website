# Ahmed Khairy

My personal website: a portfolio and journal about building things, exploring ideas, and sharing what I learn.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Writing a post

Add a Markdown file to `src/content/blog/`.
